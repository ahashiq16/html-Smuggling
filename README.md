# html-Smuggling
====================================================================
                        HTML SMUGGLER (CLI)


Description:
------------
HTML Smuggler is a lightweight, high-performance command-line 
utility designed for security researchers, penetration testers, 
and red teams. It streamlines the process of encoding payloads 
into benign HTML/JS files to test browser security controls and 
defense evasion mechanisms directly from your terminal.

Author & Developer:
-------------------
Created by ❤️  Alamin Ashiq (bangladesh)


Prerequisites:
--------------
1. Terminal / Command Prompt:
   As a CLI-driven tool, you need access to a terminal environment 
   (e.g., Windows CMD/PowerShell, Linux Terminal, or macOS Terminal).

2. Node.js Environment:
   Node.js must be installed on your system to run this application.
   (Download Node.js: https://nodejs.org)

Quick Setup & Usage:
--------------------
1. Open your terminal in the project directory.
2. Install dependencies:
   $ npm install

3. Run the application:
   $ node index.js

Key Features:
-------------
* 100% CLI-Driven: Optimized for fast, automated execution.
* Payload Encoding: Converts scripts or binaries into stealthy HTML payloads.
* Defense Testing: Helps assess browser detection & endpoint security.
* Lightweight: Zero heavy dependencies and fast execution.
